# Sources

Cutout art bundled with the library and reachable from a spec by NAME
(`STICKER_LIBRARY` in `src/templates/sticker/library.ts`):

```json
{ "template": "sticker", "props": { "src": "pickle" } }
```

| File | Name | Size | Origin | License |
|---|---|---|---|---|
| `pickle.png` | `pickle` | 1024x1024 RGBA | First-party art, produced 2026-08-15 | Ships with OverlayMotion; no third-party rights attached |

Nothing here is redistributed from a stock or CC library, which is the whole
bar for this folder: art the project cannot license onward stays a path or a
URL in the caller's own spec. The generator used for `pickle.png` was not
recorded at the time; the file carries only ImageMagick timestamps.
